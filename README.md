# RNA-Seq Data Analysis
This repository contains some scripts to map short read RNA-Seq data to the reference genome using [salmon](https://combine-lab.github.io/salmon/), [kallisto](https://pachterlab.github.io/kallisto/about)
and [STAR](https://github.com/alexdobin/STAR) methods and also running Differentially Expressed Gene (DEG) analysis using [limma](https://bioconductor.org/packages/release/bioc/html/limma.html)
, [edgeR](https://bioconductor.org/packages/release/bioc/html/edgeR.html) and [DESeq2](https://bioconductor.org/packages/release/bioc/html/DESeq2.html).

There are also some other R scripts to visualizing the results, removing inflation using [bacon](https://www.bioconductor.org/packages/release/bioc/html/bacon.html), calculating Surrogate Variables 
using [SVA](https://bioconductor.org/packages/release/bioc/html/sva.html).
